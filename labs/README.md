# 演習

この演習では、サンプルをそのまま登録するのではなく、実環境のスキーマを確認してからカスタム推奨事項に仕上げます。

## 演習一覧

1. [AWS: RDS の公開アクセスを検査する](aws.md)
2. [GCP: Compute Engine の IP forwarding を検査する](gcp.md)
3. [設計レビュー: できること・できないことを判定する](query-design-review.md)

## 共通の完了条件

- 実環境から `Identifiers.Type` を取得している
- 使用フィールドと実行時の型を記録している
- 正常資産と異常資産の期待結果を記録している
- 必須7列を返している
- 欠損値の扱いと適用除外を説明できる
- 単一資産、配列、関連資産、日時比較のどのパターンか説明できる
- `RawEntityMetadata` だけでは実現できない要件を識別できる
- 製品内 HELP と参考 KQL のどこを根拠にしたか記録している
- 登録後の評価結果を Defender for Cloud と Azure Resource Graph で確認している
